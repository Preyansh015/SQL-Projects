# Dataset Overview

This project uses the official **Brazilian E-Commerce Public Dataset by Olist** hosted on Kaggle. 

* **Source / Official Link:** [Kaggle Brazilian E-Commerce Dataset](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)
* **Description:** The dataset contains information on 100,000 orders from 2016 to 2018 made at multiple marketplaces in Brazil. It allows orders to be viewed across multiple dimensions including order status, pricing, payment, freight performance, customer locations, and product attributes.

---

## 📁 Core Files Included in the Database Schema:
1. **`olist_customers_dataset.csv`** – Customer geographic data and unique IDs.
2. **`olist_orders_dataset.csv`** – Order lifecycle, statuses, and timestamps.
3. **`olist_order_items_dataset.csv`** – Individual product line items, prices, and freight shipping values.
4. **`olist_order_payments_dataset.csv`** – Payment methods and transaction values.
5. **`olist_products_dataset.csv`** – Product catalog details and categories.
6. **`olist_sellers_dataset.csv`** – Merchant origin locations.
7. **`product_category_name_translation.csv`** – English translations for product categories.

*Note: Due to GitHub file size limits, the raw CSV files are not stored directly in this repository. You can download the complete dataset directly from the Kaggle link provided above to set up your local database.*
